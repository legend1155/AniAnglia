# AniAnglia v5.2 — общая стеклянная панель и рекомендации по просмотру

Это полный набор изменённых файлов относительно исходного upstream. Включает v5 и исправление сборки v5.1. Не содержит IPA: сборка выполняется вашим GitHub Actions.

## Установка
1. Скопируйте СОДЕРЖИМОЕ `changed-files` в корень репозитория с заменой, сохраняя вложенные пути. Саму папку changed-files в проект добавлять не надо.
2. Обязательно загрузите новые `AniAnglia/Main/WatchPolicy.hpp` и `AniAnglia/Main/WatchHistory.h`. Это заголовки, отдельно добавлять их в Compile Sources не нужно.
3. Закоммитьте файлы, запустите новый **Run workflow** на обновлённой ветке. Re-run старого запуска использует старый коммит.
4. Установите IPA через SideStore поверх приложения с тем же идентификатором. Не удаляйте приложение, если хотите сохранить локальные данные.

Альтернативы (не применять вместе с копированием файлов): `AniAnglia-v5.2-full.patch` для чистого upstream b30a663a7a070dec687aef31441ed60fb7ac6ff4; `v5.1-to-v5.2.patch` только для исходников точной предыдущей v5.1.

## Плеер
- Одна общая панель с единым состоянием видимости. Тап по свободной области видео показывает/скрывает её целиком. При воспроизведении скрывается через 4 секунды; касания кнопок не переключают видимость случайно.
- Skip, «Далее», меню опенинга, закрытие, время, ползунок и воспроизведение скрываются вместе. Постоянной плавающей кнопки-глаза больше нет.
- Play/Pause, ±10 секунд, перемотка, скорость 0.5–2×, AirPlay. Ползунок и меню не должны прятаться во время взаимодействия; после паузы панель появляется. VoiceOver/Switch Control отключают автоскрытие.
- Стиль: системный ultra-thin blur, полупрозрачная подложка, тонкая светлая обводка, округлые кнопки и SF Symbols. Это доступный UIKit-стиль, не обещание точного воспроизведения неизвестного будущего интерфейса iOS. При снижении прозрачности используется непрозрачный фон.
- ВАЖНО: синхронизация сделана собственной панелью, а не отслеживанием приватных элементов AVKit. AVPlayerViewController остаётся контейнером воспроизведения, но его встроенная панель выключена. Это не полная копия всех штатных меню AVKit: отдельной кнопки ручного PiP и выбора дорожек/субтитров в новой панели пока нет. Автоматический PiP оставлен через публичную настройку AVKit на iOS 14.2+, поведение на устройстве не проверено.
- Границы AniSkip, условия автоскипа и сохранение позиции не менялись. Добавлен только сброс измерителя времени при перемотке/скипе, чтобы не записывать пропущенный опенинг как просмотренный.

## Рекомендации
- Новая локальная история начинает собираться после установки v5.2. Старый `playback_progress` — лишь позиция возобновления, из него нельзя честно восстановить просмотренные минуты, поэтому он не используется для обучения.
- Учитываются уникальные целые секунды действительно воспроизводившихся участков видео. Пауза, буферизация, восстановление позиции, скачки перемотки и интервалы пропущенных callback не засчитываются. При недостоверном измерении время скорее недосчитается, чем будет угадано.
- Повторный просмотр тех же секунд в той же серии не удваивает сигнал. При надёжном номере серии ключ общий для источников, иначе используется источник + его позиция. Разная длительность монтажа более чем на секунду сбрасывает покрытие этого ключа.
- Измеряется покрытие временной шкалы видео: 10 минут контента на скорости 2× — 10 минут просмотренного контента, а не 10 минут настенных часов. Просмотр в PiP учитывается при работающих callback; фоновое аудио без PiP — нет. Работа PiP на устройстве требует проверки.
- 25% серии при достаточном числе минут дают слабый положительный сигнал; 50% — средний; 80% — более сильный. Формула учитывает и долю, и продолжительность, поэтому десять минут фильма не равны десяти минутам обычной серии. Несколько просмотренных серий усиливают интерес, но вклад одного аниме ограничен, чтобы длинный сериал не забил весь вкус.
- Короткий выход НЕ означает автоматически «не понравилось». Рейтинг 1–2 и «Неинтересно» понижают похожие жанры; рейтинг 4–5, избранное и выбранные жанры дают положительные сигналы. Это объяснимая жанровая эвристика, не модель, точно определяющая эмоции.
- Уже известные/смотрящиеся/скрытые тайтлы по-прежнему исключаются из новых рекомендаций. На главной показывается количество учтённых минут. Обновление срабатывает после сохранённого изменения истории при возвращении на главную; доступно ручное обновление.
- Хранение отдельно по ID профиля на устройстве, без отдельного сервера и отправки статистики. Запись примерно каждые 15 секунд, при закрытии/переходе серии и уходе приложения в фон. Аварийное завершение может потерять последние секунды.
- Лимит: последние 100 аниме, по 50 записей серий на аниме и не более 300 записей серий всего, видео до 5 часов. Покрытие на диске сжато в диапазоны. Это не бессрочная история всех просмотров.
- «Мои жанры» → «Сбросить» → «Сбросить обучение по просмотру» удаляет только новую статистику, не позицию возобновления. «Вернуть скрытые аниме» также убирает отрицательные жанровые сигналы от скрытия.
- Кандидаты по-прежнему берутся из ограниченного числа страниц каталога. Избранное и оценки читаются с первой страницы доступных данных. Без жанров в метаданных просмотренного аниме его минуты не могут обучить жанровую модель.

## Проверка перед передачей
- 240 C++ проверок production-логики: воспроизведение, подбор, уникальное покрытие, перемотки/паузы/скачки времени, скорость, правила видимости и отрицательные сигналы.
- Статические проверки подключения и сохранности метода saveProgress, CoreMedia и исправления UIBarButtonItem.
- Проверка применения обоих патчей, побайтового совпадения файлов, ZIP CRC и SHA-256.
- НЕ выполнены: компиляция iOS/Xcode, проверка UIKit на экране, взаимодействие с реальным AVKit/PiP, реальный сетевой просмотр Kodik/AniLibria. Linux не содержит iOS SDK. Необходимо собрать в Actions и проверить на iPhone.

## Короткий тест на iPhone
1. Запустить серию: проверить стеклянные кнопки, Play/Pause, ползунок, ±10, скорость, AirPlay.
2. Не трогать экран 4 секунды: ВСЕ кнопки должны исчезнуть. Тапнуть свободную область: всё возвращается. На паузе панель не исчезает автоматически.
3. Открыть меню опенинга и проверить скролл/кнопки, затем автоскип на известном рабочем видео. Убедиться, что он не зависит от видимости панели.
4. Посмотреть 1–2 минуты, закрыть и вернуться на главную: число учтённых минут должно увеличиться. Перемотать на 15 минут вперёд: само перемещение не должно добавить 15 минут статистики.
5. Продолжить просмотр значительной части серии, затем следующей: должна меняться жанровая выдача при наличии подходящих новых кандидатов.
6. Перезапустить приложение: позиция возобновления и новая статистика должны сохраниться. Проверить сброс обучения — позиция не удаляется.

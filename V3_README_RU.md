# AniAnglia v3 — Skip по границам конкретной серии

## Важно: что теперь означает «корректный Skip»

Приложение больше НЕ использует общий интервал «начало 0, длительность 90 секунд».
Skip выполняется только по сохранённым, подтверждённым пользователем границам текущей серии.
Это не распознавание музыки/картинки и не обещание наличия разметки для любого аниме.

Метки привязаны к профилю, релизу, источнику, позиции серии, адресу потока без query/fragment
и длительности видео (допуск 1 секунда). При изменении этих признаков метки не применяются.
Это консервативная защита, а не криптографическое определение версии: если провайдер заменит
монтаж по тому же адресу на видео той же длительности, автоматически выявить это нельзя.
Изменение CDN/пути может, наоборот, потребовать повторной разметки даже того же видео.

## Установка поверх v1/v2

1. Распаковать архив AniAnglia-v3.zip.
2. Загрузить СОДЕРЖИМОЕ `changed-files` в корень своего форка, сохраняя пути и заменяя файлы.
   Саму папку `changed-files` в репозитории создавать не надо.
3. Обязательно заменить и PlayerViewController.mm, и PlaybackPolicy.hpp, и настройки, и тесты.
   Все предыдущие исправления также включены. Папка `.github` может быть скрыта в файловом менеджере.
4. Закоммитить в master. Actions → Build iOS App → Run workflow → master.
   НЕ Re-run у старого запуска — он использует старый commit.
5. Успешную IPA установить через SideStore поверх старой, не меняя Bundle ID.

Полный .patch в архиве — альтернативный вариант только для ЧИСТОГО исходного commit
b30a663a7a070dec687aef31441ed60fb7ac6ff4. Не применять его поверх уже внесённых v1/v2.
Для существующего форка использовать замену файлов.

## Как задать точный опенинг без внешних сервисов

Во встроенном плеере нажать `Опенинг · настроить`.

Вариант A:
- Перемотать к первому кадру опенинга → Опенинг → Начало опенинга сейчас.
- Дойти/перемотать к первому кадру ПОСЛЕ опенинга → Опенинг → Конец опенинга сейчас — сохранить.

Вариант B:
- Опенинг → Ввести начало и конец.
- Ввести, например, начало `00:30`, конец `02:00` — именно конец, не длительность.
- Допустимы секунды, mm:ss и hh:mm:ss, включая десятичные доли секунд.

Разметка сохраняется только для этой серии/потока. Она не копируется на следующую серию.
Во время незавершённой разметки и просмотра предложенных таймкодов автопропуск опенинга приостановлен.
В меню можно отменить разметку/просмотр и вернуться к сохранённым меткам.
Меню приостанавливает воспроизведение для проверки. «Начало сейчас» продолжает просмотр,
а после ввода границ/просмотра кадров при необходимости нажать Play.
Кнопка «Вписать видео» теперь находится внутри меню «Опенинг», чтобы не перегружать экран.

## Таймкоды AniSkip — необязательный источник готовых границ

1. Опенинг → Настроить AniSkip.
2. Указать ЧИСЛОВОЙ MyAnimeList ID именно этого сезона и номер текущей серии в нём.
   Это НЕ ID Anixart. Текущая модель libanixart не содержит MAL ID, поэтому подставлять
   числовой ID релиза Anixart в запрос AniSkip нельзя.
3. Привязка сезона и смещения нумерации сохраняется для этого релиза/источника/профиля.
   Следующие серии используют рассчитанный номер в этом сезоне, но их границы не наследуются.
4. Приложение запрашивает op-интервал у публичного API AniSkip. При единственном валидном
   результате и расхождении длительности не более 1 секунды появляется «Опенинг · проверить».
5. Проверить начало/конец по видео и нажать «Границы верны — сохранить».
   До подтверждения полученные данные НЕ запускают Skip, даже при включённом автопропуске.

Сервис использует разметку сообщества: возможны ошибки, неполное покрытие и отличия монтажа.
Нельзя гарантировать точность только по совпадению MAL ID и общей длительности.
Поэтому эта версия требует подтверждения для каждой новой серии. Полностью безручное
распознавание опенинга для всех видео НЕ реализовано.

Сеть не используется, пока нет настроенной MAL-привязки. После настройки отправляются
MAL ID, номер серии и её длительность. Видео, токен Anixart и профиль пользователя не отправляются.
Сохранённые метки локальны; приложение не публикует их в AniSkip.
Чтобы отключить запросы: изменить привязку и оставить поле MAL ID пустым.
API/контракт: https://github.com/aniskip/aniskip-api
GET /v2/skip-times/{malId}/{episode}?types=op&episodeLength={seconds}

## Поведение кнопки и автопропуска

- Skip виден только внутри подтверждённого интервала. Нажатие вне интервала ничего не перематывает.
- Автопропуск включается в Настройки → Воспроизведение → Автопропуск опенинга.
- Он срабатывает не более одного раза на сеанс серии, только во время воспроизведения, не на паузе.
- При перемотке назад в опенинг кнопка ручного Skip доступна снова, но автоматического цикла нет.
- Если возобновить просмотр уже после опенинга, никакой дополнительной перемотки нет.
- События AVPlayer на границах интервала плюс обновление 4 раза в секунду заменяют грубый секундный опрос.
- Используется seek с нулевыми допусками до/после. Реальная точность зависит от AVPlayer и видеопотока.
- Нет границ, ответ неоднозначен, длительность неизвестна, данные повреждены или сервис недоступен:
  опенинг не пропускается, можно отметить его вручную. Ошибка сервиса не блокирует воспроизведение.
- После ухода на другую серию старые сетевые ответы и открытые редакторы не могут сохранить метки в неё.
- Для веб-плеера SafariServices собственный Skip недоступен. Нужен встроенный iOS-плеер.

Настройка пропуска последних секунд серии из v2 остаётся отдельной функцией и по-прежнему
использует заданное число секунд, а не распознанные титры. v3 меняет именно опенинги.

## Проверки и ограничения

Локально выполнены:
- 80 C++20 проверок используемых функций: качество, очередь, границы, подтверждение,
  несовпадение длительностей, парсинг времён, недопустимые и нечисловые значения.
- Проверки исходника против регрессии несуществующего свойства PiP и общего таймера.
- Публичный GET к AniSkip: HTTP 200 и ожидаемые поля skipType/interval/episodeLength/skipId.
  Это проверка контракта на публичном примере, НЕ проверка таймкодов пользовательского аниме.
- YAML/Bash синтаксис workflow, git diff --check, применение полного патча к чистым файлам.

НЕ выполнены: компиляция iOS v3 и UI-тест на iPhone — в этой Linux-среде нет Xcode/iOS SDK.
Нужен новый GitHub Actions запуск; следующие ошибки компиляции/поведения всё ещё возможны.
Не называем неподтверждённую сборку полностью рабочей.

На iPhone проверить: разметка с ненулевым началом; сохранение и перезапуск; перемотка
до/внутрь/после опенинга; пауза; повторный просмотр; другой источник; изменившаяся длительность;
ответ AniSkip до/после смены серии; отсутствие сети; портрет/ландшафт; PiP и скрытие панели.

Остальные ограничения v2 остаются: LibriaParser не пересобран и не подтверждён на проблемной
серии; нет кеша видео/офлайн-режима; не переписаны целиком все разделы настроек приложения.

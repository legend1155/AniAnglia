# AniAnglia v5.3 — исправление панели и поиска опенингов

Полный набор изменений: включает v5.2 и все предыдущие исправления. IPA не собран локально: нужен новый запуск GitHub Actions.

## Установка
1. Содержимое `changed-files` загрузить в корень репозитория с заменой и сохранением путей. Не создавать в проекте дополнительную папку changed-files.
2. Обязательно добавить новые `AniAnglia/Releases/PlayerChrome.h` и `AniAnglia/Releases/PlayerChromeLayout.hpp`. Заголовки не надо добавлять в Compile Sources.
3. Commit → новый Run workflow на обновлённой ветке. Не Re-run старого запуска.
4. Установить IPA поверх текущего приложения с тем же bundle ID, не удалять приложение для сохранения локальных данных.

Вместо копирования: полный патч — для чистого upstream b30a663a7a070dec687aef31441ed60fb7ac6ff4; `v5.2-to-v5.3.patch` — только поверх точной предыдущей v5.2. Не применять патч и копирование одновременно.

## По скриншоту: что переделано
Ориентир — предыдущий макет с двумя экранами, не неисправный скриншот пользователя.
- У кнопки независимые передний слой иконки/текста и задний blur. Иконка не может оказаться позади стеклянной подложки. Для основных символов добавлен графический fallback, если SF Symbol не загрузится.
- Видимая стеклянная капсула высотой 30 pt, крестик — круг 30 pt, зона нажатия кнопок остаётся 44 pt. Тонкая обводка и ultra-thin material; режим снижения прозрачности учитывается.
- Перемотка, Play/Pause и перемотка вперёд — просто белые иконки БЕЗ крупных фоновых плашек. Вместо растягивания кнопок по всей ширине они собраны слева с шагом 44 pt.
- Внизу: тонкая шкала 3 pt; в строке под ней управление слева, время по центру, скорость и AirPlay справа. Маленькая круглая точка шкалы 9 pt нарисована приложением, а не системным UISlider, чтобы вид не менялся от версии iOS.
- Опенинг / Skip / Далее компактной группой справа выше шкалы. При отсутствии доступного Skip или следующей серии группа перестраивается без пустых дыр.
- Всё управление, включая затемнение снизу, исчезает вместе через 4 секунды воспроизведения и возвращается по тапу. Постоянной кнопки-глаза нет. VoiceOver/Switch Control отключают автоскрытие.
- Элементы привязываются к видимой области видео, когда она достаточно велика, а не попадают в боковые чёрные полосы. Для портретного и маленького экрана используется отдельная адаптация без пересечений.
- Скорость сохраняется при паузе/продолжении и переходе серии в рамках текущего плеера. Отменена прежняя ошибка, когда выбор скорости запускал паузу сам по себе.
- Перемотка не даёт старому completion от предыдущего seek/эпизода сбросить состояние новой операции. Небольшой допуск 0.2 с для ручной перемотки уменьшает требование покадрового позиционирования HLS; автоскип по границам остаётся точным.

Это изменение кода под показанную композицию, НЕ заявление о подтверждённом совпадении до пикселя. Точный blur зависит от iOS и видео; реальную сборку ещё надо проверить на iPhone. Портретный режим намеренно отличается от горизонтального макета. Встроенные меню AVKit по-прежнему заменены общей панелью, как в v5.2; ручная кнопка PiP/выбор дорожек в этом обновлении не добавлены.

## Почему опенинг мог не находиться, что исправлено
- Раньше использовался один поисковый запрос. Теперь при отсутствии совпадения проверяются до трёх доступных названий из метаданных. Год, формат и точное нормализованное название всё равно проверяются; неоднозначный сезон не выбирается по первой строке.
- Jikan может вернуть `episodes: null` у онгоинга. Такой результат теперь допускается ТОЛЬКО если он явно Currently Airing, а название, год и формат совпадают. Неизвестное число серий у завершённого тайтла не считается достаточным доказательством.
- Для AniSkip запрашиваются все версии таймкодов (`episodeLength=0`), затем приложение само сверяет реальную длительность. Это убирает ограничение поиска округлённой длительностью запроса. Одинаковые повторяющиеся записи дедуплицируются.
- Добавлены максимум два повтора для HTTP 429/500/502/503/504 и временных ошибок сети, с ограниченным ожиданием и учётом Retry-After. Для 404 и отменённого запроса повторов нет. Между запросами Jikan сохраняется rate limit.
- Бюджет сетевого автопоиска — 45 секунд, timeout каждой попытки ограничен остатком бюджета; отложенная попытка не запускается после исчерпания бюджета. Смена серии отменяет старую цепочку; ручной повтор и новая привязка начинают новый бюджет.
- Короткие статусы на экране; подробная причина остаётся в «Опенинг → Диагностика AniSkip → Скопировать».

### Чего нельзя обещать
AniSkip не содержит таймкоды для каждого аниме/эпизода/монтажа. Если разметки нет, автоскипа не будет. Если длительность отличается больше чем на секунду, кандидат доступен для проверки, но НЕ применяется автоматически. Разные подходящие интервалы требуют ручного уточнения. Не добавлен случайный пропуск первых 90 секунд или фиктивное распознавание видео.

На присланном скриншоте длительность 46:51. Это само по себе не ошибка, но разметку другого, например 24-минутного монтажа нельзя переносить на него без проверки. Для точечного исправления нужны название/сезон/номер серии и скопированная диагностика. По одному кадру нельзя честно установить причину отсутствия разметки.

## Что сохранено
Метод сохранения позиции побайтово не менялся. Учёт реально просмотренных участков и рекомендации v5.2 сохранены. Перемотки/скипы не засчитываются как просмотр. Привязанные вручную интервалы и настройки сохраняются.

## Проверки
343 проверки production C++-логики: playback, подбор, учёт покрытия, правила привязки, сетевые повторы и геометрия кнопок. Проверены попадание всех областей в экран и отсутствие пересечений для 5 размеров, всех комбинаций Skip/Далее и обычного/крупного текста. Дополнительно — статические проверки слоёв, запуска URLSession-задач, защиты от старого seek, CoreMedia и метода сохранения позиции.

Из той же геометрии сделаны и визуально просмотрены HTML-схемы горизонтального, вертикального и скрытого состояния. Это НЕ рендер UIKit и НЕ подтверждение работы на устройстве. Проверены применение полного/обновляющего патчей и SHA-256 архива.

Не выполнены: компиляция iOS/Xcode, реальный рендер UIKit, реальные жесты/AVKit/PiP и поток конкретного аниме пользователя. В Linux нет iOS SDK.

## Проверить на iPhone
1. Видны ли крестик, обе перемотки и Play/Pause; нет ли пустых капсул.
2. Соответствует ли горизонтальная композиция макету, тонкая ли шкала и маленькая ли круглая точка.
3. Тап/автоскрытие/пауза, быстрые повторные перемотки, поворот, смена серии, скорость на паузе и после продолжения.
4. Рабочий ранее эпизод AniSkip, затем проблемный. Если не найдено — прислать диагностику и новый скрин панели.

# AniAnglia v2 — исправление сборки и кнопки Skip

## Для текущего форка legend1155/AniAnglia

1. Распаковать архив AniAnglia-v2.zip.
2. Скопировать СОДЕРЖИМОЕ `changed-files` в корень своего репозитория с заменой файлов и сохранением путей. Саму папку `changed-files` в репозитории создавать не надо.
3. Обязательно загрузить новый `AniAnglia/Releases/PlaybackPolicy.hpp`, а не только `.mm`: плеер использует этот заголовок.
4. В `changed-files` есть скрытая папка `.github`. Обновить `.github/workflows/build.yml` тоже: через редактор GitHub или вместе с остальными файлами. В тестовом шаге нужны оба файла из `tests`.
5. Закоммитить изменения в `master`. На вкладке Actions выбрать Build iOS App → Run workflow → master.
6. НЕ нажимать Re-run у старого запуска: он использует старый commit! Запустить новый workflow после коммита.
7. Успешный запуск выдаст артефакт AniAnglia.ipa. Неуспешный — build-log, если начался шаг xcodebuild.
8. Установить новую IPA через SideStore поверх старой, не меняя Bundle ID.

`AniAnglia-v2-full.patch` — альтернативный полный патч от ЧИСТОГО исходного commit
b30a663a7a070dec687aef31441ed60fb7ac6ff4. Не применять его поверх v1; для текущего форка использовать замену файлов по инструкции выше.

## Ошибка в присланном логе

PlayerViewController.mm:36:
`property 'pictureInPictureActive' not found on object of type 'PlayerViewController *'`.
В прошлом патче было использовано несуществующее свойство AVPlayerViewController.
В v2 его нет: PiP отслеживается по событиям AVPlayerViewControllerDelegate.
Boost warnings и общий exit code 65 не были первопричиной.

## Новое в v2

- Встроенный AVPlayerViewController находится внутри полноэкранного контейнера.
  Кнопки — отдельные интерактивные views поверх видео, не в неинтерактивном contentOverlayView.
- `Skip · Опенинг`: показывается только внутри настроенного интервала опенинга.
  Работает вручную, даже если автопропуск выключен. На последней секунде интервала скрывается.
- `Следующая серия →`: доступна при наличии следующей позиции в реальном списке серий.
  На последней серии отсутствует. Ранний ручной переход сохраняет позицию и не помечает текущую серию просмотренной.
- `Вписать видео`: возвращает режим отображения Aspect Fit; это ручное восстановление масштаба,
  а не подтверждённое исправление всех жестов AVKit.
- `Скрыть панель` / `Показать панель`: явное управление штатной панелью и дополнительными кнопками.
  Небольшая кнопка показа остаётся доступной. Нет добавленного прозрачного обработчика жестов на весь экран.
- Индикатор загрузки и кнопка повторной попытки при ошибке потока.
- Настройка `Пропускать конец серии` и количество последних секунд до перехода.
  Это отдельный переключатель, который запускает переход ДО конца, независимо от автоперехода после естественного завершения.
  По умолчанию выключен; продолжительность 90 секунд. Последняя серия не обрывается.
- Автоматические пропуски выполняются во время воспроизведения, не во время паузы/поиска позиции.
- Переходы защищены от устаревших асинхронных ответов и двойного переключения.
- Озвучка в настройках выбирается из загружаемого списка с поиском, а не вводится точным текстом.
  Список источников в настройках собирается при открытии списков источников релизов.
- Более бережное сохранение прогресса: каждые ~5 секунд, при закрытии и уходе в фон.
- Метка просмотренной серии отправляется при завершении/включённом пропуске конца, не при старте.
- Кнопка скачивания сообщает о недоступности офлайн-режима вместо имитации действия.
- Workflow запускает тесты логики, сохраняет build.log и сокращает шум документационных warnings.

Все возможности v1 также входят в архив: настройки качества/плеера/предпочтений, сортировка
серий и озвучек/источников, кеш изображений, сохранение позиции и веб-вариант при ошибке парсера.

## Проверено здесь

- Найдена точная ошибка в присланном ZIP-логе; её вызов удалён из исходника.
- 38 проверок C++20 для используемых плеером функций: качество, реальные позиции следующей серии,
  опенинг с ненулевым началом, границы интервалов, неизвестная длительность и конец последней серии.
- Статические проверки регрессии проблемного API и структуры нового контейнера.
- Синтаксис YAML/Bash workflow и `git diff --check`.
- Применение полного патча к чистым исходным файлам и совпадение результатов с вложенными исходниками.

## Что ещё НЕ подтверждено / не реализовано

- На Linux нет Xcode/iOS SDK: сборка iOS v2 здесь НЕ выполнялась. Нужен новый запуск GitHub Actions.
  Удаление ошибки из прошлого лога не гарантирует отсутствие следующих ошибок компиляции.
- Нет теста на настоящем iPhone. Проверить портрет/ландшафт, нажатия Skip, перемотку, паузу,
  скрытие/показ панели, PiP и выход из PiP, закрытие во время загрузки и ошибки сети.
- Для Libria нет ссылки на проблемный релиз/серию. Бинарный LibriaParser не пересобран и его
  совместимость с актуальным провайдером не подтверждена. Пока есть только обработка ошибок,
  прямой HLS/MP4 и веб-вариант. Нельзя считать Libria гарантированно исправленной.
- В веб-плеере SafariServices приложению недоступны видео страницы и собственные кнопки Skip,
  прогресс/автопереходы. Эти возможности относятся только к встроенному iOS-плееру.
- Опенинг/титры не распознаются автоматически: используются общие временные настройки.
  У разных аниме интервалы отличаются; включать автообрезку нужно осознанно.
- Кешируются изображения по HTTP-политике сервера; видео/офлайн-загрузка и кеш C++ API не реализованы.
- Сортировка добавлена для серий, озвучек и источников. Для каталога уже есть фильтр сортировки
  исходного проекта; универсальная сортировка всех остальных экранов не реализована.
- Все настройки приложения целиком не переписаны. Разделы уведомлений/справки/правил и смена
  email/пароля не реализованы этим патчем. Профиль/приватность по-прежнему зависят от API проекта.
- Новые тексты на русском. Полной локализации и автоматизированных UI-тестов пока нет.

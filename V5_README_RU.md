# AniAnglia v5 — плеер, поиск и персональная главная

## Установка

Архив — исходники и патчи, НЕ готовая IPA. Включены все изменения v1–v4.1,
в том числе исправление CoreMedia. GitHub автоматически этим архивом не обновляется.

1. СОДЕРЖИМОЕ `changed-files` перенести в корень форка с заменой и сохранением путей.
   Не загружать папку `changed-files` как отдельную папку внутри проекта.
2. Добавить новые файлы:
   - `AniAnglia/Main/DiscoveryPolicy.hpp`
   - `AniAnglia/Main/ModernStyle.h`
   - `tests/fixtures/aniskip_54595_4.json`
   Также сохранить заголовки PlaybackPolicy.hpp и AnimeMapping.hpp предыдущих версий.
   Эти заголовки подключены по относительным путям, отдельные записи компиляции Xcode им не нужны.
3. Заменить остальные файлы из комплекта, включая `AniAnglia.xcodeproj/project.pbxproj`,
   `.github/workflows/build.yml`, тесты и изменения главной/поиска/провайдера страниц.
4. Сделать commit → Actions → Build iOS App → Run workflow на обновлённой ветке.
   Не Re-run старого запуска: он использует старый commit.
5. После успешной сборки скачать IPA и установить через SideStore поверх старой версии
   с прежним Bundle ID. Не удалять приложение для обновления: удаление стирает локальные данные.

Варианты патчей:
- `AniAnglia-v5-full.patch` — ТОЛЬКО на чистую основу b30a663a7a070dec687aef31441ed60fb7ac6ff4.
- `AniAnglia-v4.1-to-v5.patch` — ТОЛЬКО на точные файлы из v4 с установленным фиксом v4.1 CoreMedia.
Не применять оба патча. Для существующего форка проще заменить файлы из changed-files.
Если вручную менялся Bundle ID или другие настройки проекта, сохранить эти изменения:
не затирать свою конфигурацию вслепую, использовать проверку патча/сравнение файлов.

## 1. Контрольный пример: «Восхождение в тени», сезон 2, серия 4

Добавлена встроенная проверенная привязка сезона к MAL 54595: TV, 2023, 12 серий.
Поддержаны точные нормализованные русские/оригинальные/английские варианты названия.
Известные год, формат и число серий по-прежнему проверяются — ID не назначается просто
по подстроке «Восхождение в тени». Это одна проверенная запись для контрольного сезона;
остальные релизы по-прежнему используют автоматический поиск через Jikan.
Ручная MAL-поправка, если ранее сохранена пользователем, имеет приоритет.

Публичный AniSkip при проверке вернул для MAL 54595 / эпизода 4:
- начало op: 133.189 с (02:13.189);
- конец op: 223.189 с (03:43.189);
- длительность размеченной версии: 1422.467 с (23:42.467).

Эти таймкоды НЕ зашиты в приложение как безусловный fallback. В приложении всё равно
выполняется запрос для текущей серии и длительности. Записанный ответ находится в tests/fixtures
исключительно для тестов. Сам поток пользователя Kodik/AniLibria не был получен и проверен;
поэтому причина конкретного отказа на устройстве ещё не доказана и точность для этого монтажа
не гарантируется одним совпадением сезона. Проверенная привязка устраняет зависимость
этого сезона от поисковой выдачи Jikan, но не заменяет проверку самого видео.

Источники проверки:
https://myanimelist.net/anime/54595/Kage_no_Jitsuryokusha_ni_Naritakute_2nd_Season
https://api.aniskip.com/v2/skip-times/54595/4?types=op&episodeLength=0

## 2. Опенинг и диагностика

В меню «Опенинг» добавлена «Диагностика AniSkip»: название, позиция источника, MAL ID,
номер серии MAL, длительность видео, автоматическая/ручная привязка, статус запроса.
Текст можно явно скопировать кнопкой. URL потока и токен в диагностике не показываются.

Статусы теперь различают поиск, HTTP-ошибку, отсутствие op-разметки, неоднозначные интервалы
и несовпадение длительности с указанием обоих значений и разницы.

- Единственный подходящий интервал и разница длительностей до 1 секунды: применение автоматически.
- Единственный валидный интервал, но другая длительность: только предложение для ручной проверки.
  Оно НЕ запускает автопропуск до проверки обеих границ и явного подтверждения пользователем.
- Нет надёжных данных: обычный просмотр, без произвольной перемотки на 90 секунд.
- Кнопка «Пропустить опенинг» доступна внутри сохранённого интервала.
- При возврате назад автоматического цикла нет, ручной Skip остаётся доступным.
- Собственные ручные метки не перезаписываются ответами сервиса.
- Автоматические метки теперь содержат MAL/номер серии/данные релиза. Старые полученные из AniSkip
  метки v4 без этих сведений один раз запрашиваются заново; ручные границы сохраняются.
- Расширены обычные подписи серий: например, «Серия №4», «4-я серия», «Episode 04», «4 серия из 12».
  Спецвыпуски и неоднозначные подписи не превращаются в обычный номер наугад.

Это разметка сообщества, НЕ распознавание звука/видео. Равная длительность не доказывает
одинаковый монтаж. Обещания «всегда правильно для любого аниме» нет.
В SafariServices/web-плеере управление Skip по-прежнему принадлежит сайту.

## 3. Переходы и сохранение просмотра

После фактического конца серии проверяются текущий AVPlayerItem, поколение воспроизведения,
готовность плеера, отсутствие уже начатого перехода и наличие следующей реальной позиции.
На последней серии выводится завершение просмотра, повторный запуск не производится.

Автопереход включается один раз при первом запуске v5; последующее ручное выключение сохраняется.
Пропуск последних секунд/титров остаётся отдельной опцией, выключенной по умолчанию.
Если она уже включалась раньше, пользовательское значение не сбрасывается: для просмотра
до фактического конца её нужно выключить в настройках.

Метод сохранения прогресса оставлен побайтно прежним; это проверяется отдельной хеш-проверкой.
Формат/ключи прогресса не мигрируются и не удаляются. Обновление без удаления приложения
и с прежним Bundle ID необходимо для сохранения пользовательских данных.

## 4. «Тебе понравится» на главной

На главной первым разделом стала подборка; прежние разделы каталога оставлены рядом.
Добавлены всегда видимые кнопки «Расширенный поиск» и «Мои жанры».

Подбор выполняется локально на данных существующего Anixart API, без нового сервера:
- выбранные пользователем жанры;
- доступная страница избранного;
- доступная страница оценок (4–5 из 5);
- популярный каталог и дополнительные страницы двух сильнейших жанров;
- история используется для исключения недавнего просмотра, не как доказательство симпатии.

Показываются до 24 уникальных кандидатов, сначала по совпадениям жанров, затем по рейтингу.
Пояснение на карточке: «Твои жанры: …» либо «Популярное в каталоге».
Без данных о вкусах подборка честно обозначается как популярная стартовая, не персональная.

По доступным признакам исключаются просмотренное, брошенное, избранное, текущее «смотрю»,
недавно открытое и скрытое. Источники читаются ограниченными страницами, а не исчерпывающим
экспортом истории: при неполных данных отдельные уже знакомые тайтлы могут остаться.
Если часть запросов не удалась, показывается предупреждение о неполной подборке.

Обновление — потянуть вниз. Пересчёт также происходит после изменения жанров и при возвращении
после пяти минут. Свайп «Неинтересно» сохраняет скрытие локально (до 500 ID).
«Мои жанры → Сбросить → Вернуть скрытые аниме» отменяет скрытия.
Предпочтения и скрытия разделены по профилям. Запоздавший ответ другого профиля/поколения игнорируется.
Сбой обновления не стирает уже показанную подборку.

Это объяснимый подбор по признакам, не обученная нейросеть и не гарантия совпадения вкусов.
Избранное, оценки и списки приложением не изменяются.

## 5. Расширенный поиск

Доступен прямо с главной. Добавлены диапазон годов и сброс всей формы.
Сохранены фильтры API: жанры/исключение жанров, статус, формат, страна, студия, сезон,
длительность/число серий, доступная озвучка, возрастные категории и исключение списков.
Сортировки API: обновление, рейтинг, год, популярность.
Годы проверяются: 1900…текущий+5, начальный не позже конечного, пустые границы допустимы.

На экране текстовых результатов есть меню режима поиска: название, студия, режиссёр, автор, жанр.
Режим передаётся реальному SearchRequest.SearchBy API. История запросов сохранена;
пустые/пробельные запросы не отправляются.

Важно: текстовый поиск и фильтры каталога остаются двумя режимами — текущий FilterRequest
не содержит поля названия. Порог минимального рейтинга также не предоставляется этой схемой;
доступна сортировка по рейтингу. Неподдерживаемые сочетания не имитируются скрытым
фильтрованием одной страницы и не выдаются за полноценный поиск всего каталога.

В провайдере результатов исправлена работа смены запросов: выполняющаяся загрузка держит
свой shared_ptr пагинатора, результаты старого поколения отбрасываются, операции одного
провайдера сериализуются. Старый ответ не должен заменять выдачу нового запроса.
Эти изменения проверены статически; стресс-тест UIKit/сети на устройстве ещё нужен.

## 6. Оформление

Современный системный iOS-стиль: material-панели навигации/табов, скруглённые кнопки,
системные символы и семантические цвета, улучшенная типографика карточек, фильтров и главной.
В плеере — тёмные material-кнопки поверх AVKit, компактный переключатель видимости,
адаптация расположения действий в ландшафте, краткий статус AniSkip.
При Reduce Transparency используется непрозрачный фон. Для нового текста включён Dynamic Type.

Используются публичные API UIKit iOS 14+; новые API iOS 27 и повышение deployment target не добавлялись.
Это не заявление о точной копии интерфейса будущей iOS 27. Полной переработки всех старых
экранов приложения и проверки всех accessibility-размеров в этой среде нет.
Реальный вид, безопасные зоны, большие шрифты и взаимодействие с AVKit требуют проверки на iPhone.

## Проверки и ограничения

Выполнено локально:
- 186 C++20 проверок производственных функций плеера, привязки и подбора;
- статические проверки мест интеграции, SDK-ссылки CoreMedia и фазы линковки;
- хеш-проверка неизменности saveProgress;
- записанный публичный ответ AniSkip для контрольной серии;
- проверка 10 примеров регулярного выражения подписей под Python (НЕ ICU-тест iOS);
- YAML/Bash workflow, git diff --check, структура исходников;
- применение полного и инкрементального патчей на соответствующие основы, побайтное сравнение
  восстановленных файлов и повторные тесты на обоих результатах.

НЕ выполнены: компиляция/линковка v5 в Xcode, запуск UIKit, сквозной тест сети приложения,
проверка потока Kodik/AniLibria и взаимодействия AVKit на iPhone.
Здесь Linux без Xcode/iOS SDK; исходники не называются подтверждённо рабочей IPA.
Исправление CoreMedia v4.1 сохранено. Возможные следующие ошибки нужно оценивать по новой сборке.

Проверить на устройстве: контрольную серию и диагностику длительности; перемотку назад/паузу;
автопереход и последнюю серию; ручной переход; скрытие панели, портрет/ландшафт и PiP;
сохранённый прогресс после обновления; подбор с/без избранного и без сети; смену поисковых
запросов во время загрузки; сброс фильтров; большие шрифты и Reduce Transparency.

Токен Anixart и видео не передаются Jikan/AniSkip. Условия публичных запросов из v4 сохраняются.
LibriaParser в скомпилированной библиотеке не пересобирался; его отдельные ошибки этим релизом
не объявляются исправленными. Документы v1–v4 исторические; актуальное поведение описано здесь.

# AniAnglia v4 — AniSkip без ввода MAL ID

## Что изменилось

Цепочка теперь автоматическая: данные релиза Anixart → поиск сезона MyAnimeList через
публичный API Jikan → номер серии → op-таймкоды AniSkip → сохранение и Skip.
Не нужны свой сервер, аккаунт MyAnimeList, API-ключ и подтверждение каждой серии.
Jikan и AniSkip — внешние сервисы, поэтому для первого получения разметки нужен интернет.
База видео и источники воспроизведения приложения не заменяются.

При первом запуске v4 включаются два переключателя:
- Автопропуск опенинга.
- AniSkip: автопоиск таймкодов.

Это однократная миграция, в том числе поверх v3, где автопропуск был выключен по умолчанию.
После неё приложение сохраняет выбранные пользователем значения и больше не включает их заново.
Если автопропуск выключить, готовые метки остаются доступны для ручной кнопки Skip.
Если выключить сетевой автопоиск, прекращаются новые запросы к обоим сервисам;
ранее сохранённые границы остаются. Чтобы вообще не перематывать автоматически,
нужно выключить именно «Автопропуск опенинга».

## Как определяется сезон

- Из карточки передаются исходное, альтернативное и русское название, год, формат и число серий.
- Для поиска используется первое непустое исходное название/явно выделенный вариант.
- Варианты разделяются по ` / `, ` | `, переводу строки и `;`. Обычный `/` внутри названия не разрезается.
- Учитываются Unicode, регистр, диакритика, пробелы и пунктуация; цифры сезона не удаляются.
- Принимается только точное нормализованное совпадение одного из названий, не приблизительный первый результат.
- Известные год, формат и общее число серий должны совпасть. Если формат неизвестен,
  нужны совпадающие И год, И число серий. Если неизвестны и год, и число серий — автоматической привязки нет.
- Для OVA/ONA год может браться из `aired.from`, если поле Jikan `year` пустое.
- Поиск проходит все страницы ответа, максимум три по 25 записей. Если страниц больше,
  или есть два разных подходящих MAL ID, привязка не выбирается.
- Успешное сопоставление кешируется на 7 дней (до 200 записей); при изменении данных релиза
  кеш не подходит. Ошибки не записываются как постоянный отрицательный результат.
- ID Anixart никогда не подставляется вместо MAL ID.

Это консервативное сопоставление, а не гарантированная идентификация любого аниме.
Другие транслитерации, составные карточки нескольких сезонов, отличающееся число серий,
неизвестные данные онгоинга и расхождения между каталогами могут оставить релиз без привязки.
Тогда ручной MAL ID остаётся необязательной поправкой в меню «Опенинг».

## Нумерация серий

Список передаёт реальные позиции и названия серий. Числовые подписи вроде `1`,
`Серия 1`, `1 серия`, `Episode 1`, `Ep. 1` связываются с номером сезона;
это позволяет учитывать и источник с позицией 0 для подписанной «1» серии.
Дублирующиеся номера, спецвыпуски, дробные и непонятные подписи автоматически не угадываются.
Если подписи действительно отсутствуют, допускается только непрерывный список позиций
от 1, не выходящий за общее число серий. Неизвестная нумерация от 0 не сдвигается наугад.
Автопереход на следующую серию использует тот же список, но таймкоды запрашиваются заново.

## Когда срабатывает Skip

1. Серия открыта во встроенном iOS-плеере, известна её длительность.
2. Однозначно выбраны сезон и номер серии, либо имеется сохранённая ручная привязка.
3. AniSkip вернул один валидный интервал `op`, а длительность версии видео отличается
   не больше чем на 1 секунду. Конец интервала должен быть раньше конца видео.
4. Границы применяются сразу, без диалога подтверждения.
5. Во время воспроизведения внутри этого интервала выполняется автопропуск;
   при выключенном автопропуске там доступна кнопка Skip поверх плеера.

Если ответ пришёл уже после опенинга, обратной перемотки нет. На паузе автопропуск не выполняется.
Автоматический Skip выполняется один раз за сеанс серии; ручной остаётся доступным при возврате в опенинг.
Нет разметки, данных для привязки, подходящей версии видео или интернета — нет произвольного пропуска
«первых 90 секунд». Воспроизведение не зависит от успешности внешних запросов.
Запоздавшие ответы после закрытия/смены серии игнорируются по поколению воспроизведения и версии запроса.
Запросы Jikan выполняются последовательно с промежутком минимум 1,1 секунды; после 429 нет бесконечных повторов.
Повторить поиск можно в меню «Опенинг».

Ручная разметка имеет приоритет и не перезаписывается фоновым ответом. Во время ручной разметки
или предпросмотра автоматическое применение приостановлено; полученное предложение можно проверить в меню.
При изменении ручного MAL ID старые полученные из AniSkip метки этого релиза/источника/профиля удаляются,
а собственные ручные границы сохраняются. Пустой MAL ID удаляет ручную поправку и возвращает автопоиск.

Важно: AniSkip использует разметку сообщества, не анализ самого видео. Ошибки в разметке возможны.
Одинаковый сезон и длительность не доказывают одинаковый монтаж. Это не распознавание звука/картинки,
не аудио-отпечатки и не гарантия поддержки каждого аниме. Веб-плеер в SafariServices не управляется этим Skip.
Пропуск последних секунд серии — прежняя отдельная опция; титры здесь не распознаются.

## Локальное сохранение и приватность

Границы и прогресс хранятся локально. Метки связаны с профилем, релизом, источником,
позицией, URL потока без query/fragment/учётных данных и длительностью видео.
Jikan получает поисковое название, страницу и размер страницы. AniSkip получает MAL ID,
номер серии и длительность. Код не отправляет этим сервисам видео, токен Anixart,
профиль, сохранённый прогресс или URL видеопотока и ничего не публикует в их базы.
Удалённые сервисы при этом видят обычные сетевые сведения запроса, например IP.

## Установка в существующий форк

1. Распаковать `AniAnglia-v4.zip`.
2. СОДЕРЖИМОЕ `changed-files` загрузить в корень форка с заменой файлов и сохранением путей.
   Не создавать в репозитории отдельную папку `changed-files`.
3. Обязательно добавить новый `AniAnglia/Releases/AnimeMapping.hpp`, заменить оба файла плеера,
   `PlaybackPolicy.hpp`, `ReleaseViewController.mm`, `EpisodeSelectViewController.mm`, настройки и тесты.
   Для новых заголовков отдельная запись в Xcode project не нужна: они подключаются из соседних файлов.
   В архиве есть все накопленные изменения предыдущих версий и `.github/workflows/build.yml`.
   `.github` может быть скрыта файловым менеджером.
4. Закоммитить файлы. Actions → Build iOS App → Run workflow → нужная ветка.
   Не выбирать Re-run у старой сборки: он использует старый commit.
5. После успешной сборки скачать IPA из артефактов и установить через SideStore
   поверх прежней версии, сохранив Bundle ID. Удаление приложения удалит локальные данные.

`AniAnglia-v4-full.patch` — альтернативный вариант ТОЛЬКО для чистой исходной версии
b30a663a7a070dec687aef31441ed60fb7ac6ff4. Не накладывать полный патч поверх v1/v2/v3;
для уже изменённого форка использовать замену файлов из `changed-files`.
Сами исходники в GitHub этим архивом автоматически не обновляются.

## Что проверено, а что ещё нет

Локально: 117 проверок производственных C++-функций, включая выбор качества, очередь,
временные границы, парсинг, точное сопоставление, неоднозначность и неполные страницы,
различия года/формата/числа серий, 0-based позиции, спецвыпуски и повторяющиеся номера;
регрессионные проверки исходника, YAML и Bash workflow, git diff --check,
применение полного патча на чистую основу и повтор тестов на восстановленном результате.

Компиляция и проверка AVKit/NSURLSession на iPhone НЕ выполнены: здесь Linux, нет Xcode/iOS SDK.
Новый прямой запрос Jikan из этой среды не удался (тайм-аут), поэтому v4 не имеет
подтверждённого сквозного сетевого теста Jikan → AniSkip → iOS. Контракт сверялся с документацией;
публичный ответ AniSkip проверялся в предыдущей версии. Локальные тесты не подменяют реальную сборку.
ASan также недоступен в этой среде из-за отсутствующей runtime-библиотеки; санитайзер-проверка не заявляется.

На устройстве проверить: тайтл с точным MAL-совпадением и имеющейся op-разметкой;
следующую серию; отсутствие разметки/сети; ручную поправку; перемотку и паузу;
сохранение после перезапуска; смену источника; портрет/ландшафт, PiP и скрытие панели.
Исправления LibriaParser в скомпилированной библиотеке этим обновлением не заявляются.
Исторические документы v1–v3 включены для остальных изменений, но их старые инструкции
по ручному подтверждению AniSkip заменены этим документом.

# AniAnglia: экспериментальный патч воспроизведения

База: AnAgTeam/AniAnglia, master, commit b30a663a7a070dec687aef31441ed60fb7ac6ff4.
Патч подготовлен локально, НЕ опубликован в исходный репозиторий.
Это исходники для проверки, не готовая проверенная IPA.

## Что изменено

- Исправлен ключ длительности пропуска: раньше читалось качество вместо секунд.
- Значения новых настроек объединяются со старыми при обновлении установки.
- Подключены разделы воспроизведения и кеша изображений.
- Озвучка и источник выбираются по названию в настройках либо запоминаются при ручном выборе. Если совпадения нет, остаётся ручной выбор. Возврат назад не запускает повторный автоматический переход.
- По умолчанию доступен встроенный iOS-плеер; дополнительно — веб-плеер источника через SafariServices.
- Качество читается из настроек. Выбор потока не падает на метках `auto`, `720p` или очень длинных числах.
- Прямые mp4/m3u8/m4v открываются без HTML-парсера.
- Ошибки парсера/потока обрабатываются с предложением веб-плеера, а не молча теряются.
- Контроллер плеера удерживается явно. Восстановление из PiP вызывает completion, показ модальных окон идёт через активную сцену. Убрано принудительное обнуление плеера при остановке PiP.
- Прогресс встроенного плеера сохраняется во время просмотра, при уходе в фон и закрытии. Ключ включает профиль, релиз, источник и позицию серии. Позиция восстанавливается после готовности AVPlayerItem, до старта воспроизведения.
- Автопереход использует реальные позиции загруженных серий, включая пропуски номеров, и не запускается после последней серии. На очередную серию берётся новая ссылка.
- Автопропуск опенинга использует настраиваемые начало и длительность (общие для всех серий). Это НЕ распознавание опенинга; стандартно начало 0 с, длительность 90 с, функция выключена.
- Серия больше не помечается просмотренной сразу после получения ссылки: автоматическая отметка выполняется по завершении встроенного воспроизведения.
- Сортировка по номеру на странице серий, по имени на страницах озвучек/источников; направление сохраняется.
- Настроен HTTP-кеш изображений через NSURLCache, лимит 0/10/50/100/250 МБ и очистка. Ответы кешируются с учётом политики сервера. Загрузка изображения больше не подменяет картинку устаревшим ответом при переиспользовании ячейки и завершает индикатор при ошибке.
- Нереализованные пункты уведомлений/справки/правил показывают сообщение вместо отсутствия реакции.

## Ограничения — прочитать до сборки

- В этой Linux-среде нет Xcode/UIKit/iOS SDK и iPhone. Сборка iOS и ручная проверка не выполнены. Нужен обязательный тест на устройстве.
- Бинарный LibriaParser внутри libanixart не пересобирался и не исправлялся. Добавлена обработка ошибок и веб-вариант, но работоспособность конкретного Libria-источника НЕ подтверждена. Необходимы ссылка на проблемный релиз/серию и проверка актуального ответа провайдера. Веб-вариант не гарантирует обход ошибок самого сайта.
- Для веб-плеера недоступны нативные прогресс, автопереход и автопропуск: SafariServices не даёт приложению доступа к видеоплееру страницы.
- Проблемы жестов/скрытия панели iOS не воспроизведены. Исправлен жизненный цикл и PiP; гарантировать устранение этих двух симптомов нельзя без устройства, версии iOS и шагов воспроизведения. Патч не вмешивается в приватные жесты AVKit.
- Кешируются только изображения, НЕ видео и НЕ ответы C++ API. Офлайн-загрузка серий не реализована. Кнопка скачивания показывает сообщение о недоступности офлайн-режима.
- Сортировка добавлена только в три перечисленных списка, не во все каталоги приложения.
- Не выполнен полный аудит всех настроек профиля/безопасности/внешнего вида. Нельзя считать исправленными вообще все настройки приложения.
- Новые подписи настроек пока на русском, без полной английской локализации.

## Применение и сборка

Вариант A — патч, из корня чистого репозитория указанной версии:

```sh
git apply --check AniAnglia-improvements.patch
git apply AniAnglia-improvements.patch
python3 tests/test_quality.py
```

Вариант B — скопировать содержимое папки `changed-files` поверх исходного проекта
(с сохранением путей). Не требуется применять оба варианта одновременно.

На Mac открыть `AniAnglia.xcodeproj`, выбрать схему `iOSAnixart`, собрать для iPhone.
Или в своём форке запустить существующий workflow `Build iOS App` через Actions → Run workflow.
Workflow создаёт неподписанную IPA, не устанавливаемую обычным нажатием; для установки
нужен подходящий способ подписи/установки, указанный в исходном README проекта.
Не запускать это в чужом upstream-репозитории от его имени.

## Проверки

Выполнены локально:
- `git diff --check`;
- 38 C++ проверок функций качества, очереди и интервалов пропуска (`python3 tests/test_quality.py`).
Это НЕ тесты сборки iOS и НЕ подтверждение работы плеера.

Перед выпуском на iPhone проверить:
1. Чистая установка и обновление со старыми настройками; настройки сохраняются после перезапуска.
2. Выбор озвучки/источника вручную, повторное открытие релиза, отсутствие предпочитаемой озвучки, возврат назад.
3. Встроенный и веб-плеер, прямой HLS/MP4, источник Libria, пустой ответ парсера и ошибка сети.
4. Перемотка вперёд/назад, скрытие панели, поворот, PiP → приложение, закрытие PiP.
5. Закрытие/повторное открытие серии, фон, перезапуск; разные профили и источники не смешивают позиции.
6. Автопереход включён/выключен, последняя серия, пропущенные номера; нет двойного перехода.
7. Пропуск выключен/включён, начало опенинга не в нуле, возобновление внутри/после интервала.
8. Лимит/очистка кеша и отключение кеша; быстрый скролл с переиспользованием ячеек и ошибки изображений.
9. Сортировка всех трёх списков не меняет выбранную серию и порядок автоочереди.
